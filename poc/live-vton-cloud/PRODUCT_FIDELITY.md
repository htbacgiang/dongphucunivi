# Product Fidelity Evaluation

AI-generated output can alter logos, lettering, fabric texture, color, collar, cuff, sleeve length, and panel boundaries. The output is a visualization, not a contractual representation of the garment or a fit/size measurement.

## First PoC SKU
Use one Product + Studio approved clean front-view garment reference image, preferably an isolated garment on a plain background.

## Review checklist
- brand logo: correct artwork, wording, placement, scale
- base and panel colors
- stripe/graphic pattern orientation and continuity
- collar type and collar color
- sleeve length and cuff shape
- seams, piping, zippers, buttons, and panel boundaries
- temporal consistency during torso turns and arm raises

Capture no participant media without separate written consent. If output materially changes protected branding or key construction details, mark the SKU not approved for customer display.
